# Sync & Versioning Guide

Synchronize directory content concurrently with active conflict detection, monitoring jobs live via WebSockets.

### 🌟 Key Features
- **Concurrent Sync:** Syncs folder pairs concurrently using optimized queue processing pipelines.
- **WebSocket Streaming:** Monitors task stats, active counts, and cancellations in real-time.
- **Conflict Handling:** Flags naming collisions or newer version conflicts dynamically for user action.

### 🚀 How to Use
1. Navigate to the **Sync & Versioning** view.
2. Select source and destination directories.
3. Choose sync type (one-way mirror or two-way sync).
4. Run the sync and inspect live stats in the bottom-right task drawer.
5. Review conflict logs in the **Logs** tab if any anomalies are reported.
