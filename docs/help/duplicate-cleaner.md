# Duplicate Cleaner Guide

Locate and prune duplicate files across your system safely using our high-performance hash index database.

### 🌟 Key Features
- **Chunked Hashing:** Uses fast SHA-256 block hashing on files to prevent UI freezes on massive directory scans.
- **Index Cataloging:** Deduplicates across millions of records by matching file size indexes in SQLite.
- **Safe Selection:** Auto-selects duplicates while keeping at least one original copy untouched.

### 🚀 How to Use
1. Open the **Duplicate Cleaner** tab from the sidebar.
2. Target a directory for duplicate checks.
3. Click **Scan for Duplicates** to process and view matching file lists.
4. Review duplicate files, check metadata, and confirm selection.
5. Click **Clean Selected** to safely prune duplicate copies.
