# File Organizer - UI

This directory contains the React-based frontend for File Organizer, which is bundled into a desktop application using Electron.

## Available Scripts

In the project directory, you can run:

### `npm start`
Runs the React app in development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm run electron`
Starts the Electron wrapper. Requires the React dev server to be running (or built assets).

### `npm run dev`
Concurrently starts the React dev server and waits for it to be ready before launching the Electron wrapper.

### `npm run build`
Builds the app for production using electron-builder. 
The output will be generated in the `dist/` directory.

### `npm test`
Launches the test runner in the interactive watch mode.
